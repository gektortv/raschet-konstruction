Подбор продольной арматуры балки по СП 63.13330.2018: пример

Разберём подбор растянутой арматуры изгибаемого элемента прямоугольного сечения с одиночным армированием — самый частый расчёт в жилых и общественных зданиях.

Исходные данные

Шарнирно опёртая балка пролётом 6 м, расчётная нагрузка 50 кН/м, сечение 300 × 600 мм, бетон B25 (Rb = 14,5 МПа), арматура A500 (Rs = 435 МПа), расстояние до центра арматуры a = 50 мм.

1. Усилие и рабочая высота

M = q·L² / 8 = 50·6² / 8 = 225 кН·м h₀ = h − a = 600 − 50 = 550 мм

2. Граничная высота сжатой зоны

Граничная относительная высота сжатой зоны зависит от класса арматуры:

ξR = 0,8 / (1 + εs,el / εb2) = 0,8 / (1 + 435 / (2·10⁵·0,0035)) = 0,493 αR = ξR·(1 − 0,5ξR) = 0,372

Для A400 получится ξR = 0,533, для A240 — 0,615. Чем ниже прочность арматуры, тем больше допустимая сжатая зона.

3. Требуемая площадь арматуры

αm = M / (Rb·b·h₀²) = 225·10⁶ / (14,5·300·550²) = 0,171 ≤ αR — сжатая арматура по расчёту не нужна ξ = 1 − √(1 − 2αm) = 0,189 As = Rb·b·ξ·h₀ / Rs = 14,5·300·0,189·550 / 435 = 1038 мм²

Если αm > αR, одиночного армирования недостаточно: увеличивают высоту сечения, класс бетона или ставят сжатую арматуру.

4. Подбор стержней и проверки

Подходящие варианты: 3Ø22 (1140 мм²), 2Ø28 (1232 мм²), 4Ø20 (1257 мм²). Для каждого проверяют:

  • расстояние между стержнями в свету — не менее диаметра и 25 мм для нижней арматуры в один-два ряда (п. 10.3.5): для 3Ø22 это (300 − 100) / 2 − 22 = 78 мм;
  • минимальный процент армирования 0,1 % (п. 10.3.6): 1140 / (300·550) = 0,69 %;
  • если стержни не помещаются в один ряд, рабочая высота считается до центра тяжести всей арматуры — требуемая площадь при этом немного растёт.

5. Тавровое сечение

Если полка в сжатой зоне, сначала проверяют, где проходит граница сжатой зоны:

Mf = Rb·b′f·h′f·(h₀ − 0,5h′f) M ≤ Mf — граница в полке: расчёт как прямоугольного сечения шириной b′f M > Mf — граница в ребре: αm = (M − Rb·(b′f − b)·h′f·(h₀ − 0,5h′f)) / (Rb·b·h₀²)

Ширину свесов полки, вводимую в расчёт, ограничивают по п. 8.1.11.

6. Не забыть

  • коэффициент γb1 = 0,9 к Rb при продолжительном действии нагрузки;
  • поперечную арматуру по наклонным сечениям и конструктивный шаг хомутов у опор — не более 0,5h₀ и 300 мм;
  • прогиб и ширину раскрытия трещин.
