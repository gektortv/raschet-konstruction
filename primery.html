2. Армирование балки 300 × 600 мм

Пролёт 6 м, расчётная нагрузка 50 кН/м, бетон B25 (Rb = 14,5 МПа, Rbt = 1,05 МПа), арматура A500 (Rs = 435 МПа), a = 50 мм.

M = 50·6² / 8 = 225,0 кН·м; Q = 50·6 / 2 = 150,0 кН; h₀ = 600 − 50 = 550 мм ξR = 0,8 / (1 + 435 / (2·10⁵·0,0035)) = 0,493; αR = 0,493·(1 − 0,5·0,493) = 0,372 αm = 225·10⁶ / (14,5·300·550²) = 0,1710 ≤ αR ξ = 1 − √(1 − 2·0,1710) = 0,1888 As = 14,5·300·0,1888·550 / 435 = 1038 мм² → 3Ø22, As = 1140 мм² Расстояние в свету: (300 − 2·50) / 2 − 22 = 78 мм ≥ 25 мм; μs = 1140 / (300·550) = 0,69 % ≥ 0,1 %
Наклонные сечения: 0,3·Rb·b·h₀ = 0,3·14,5·300·550 = 717,8 кН ≥ 150 кН c = 2h₀ = 1100 мм: Qb = 1,5·1,05·300·550² / 1100 = 129,9 кН ≥ Q = 150 − 50·1,1 = 95,0 кН c = 3h₀ = 1650 мм: Qb = 86,6 кН ≥ Q = 150 − 50·1,65 = 67,5 кН → по расчёту хомуты не требуются, шаг — конструктивный

Сайт: As = 1038 мм², принято 3Ø22; бетон воспринимает поперечную силу без хомутов, наибольший шаг хомутов у опоры 250 мм (не более 0,5h₀ = 275 мм и 300 мм).

3. Прогиб балки по понижающему коэффициенту

Та же балка, нормативные нагрузки: постоянная 31,5 кН/м, полезная 10 кН/м. Eb = 30 000 МПа для B25, k = 0,2.

Нагрузка для прогиба: 31,5 + 0,35·10 = 35,0 кН/м; M = 35·6² / 8 = 157,5 кН·м I = 300·600³ / 12 = 540 000 см⁴; D = 0,2·30 000·540 000·10⁴ = 32 400 кН·м² f = 5/48·157,5·6² / 32 400 = 0,0182 м = 18,2 мм ≤ fu = 6000 / 200 = 30,0 мм

Сайт: 18,2 мм при предельном 30,0 мм.

4. Предельный прогиб при пролёте 9,47 м

Помещения высотой до 6 м. По табл. Д.1 СП 20.13330.2016: 6 м — l/200 = 30 мм, 12 м — l/250 = 48 мм.

Интерполяция прогибов: fu = 30 + (48 − 30)·(9,47 − 6) / 6 = 40,41 мм (l/234) Интерполяция знаменателей: n = 200 + 50·3,47 / 6 = 228,9; fu = 9470 / 228,9 = 41,37 мм

Сайт: 40,4 мм или 41,4 мм в зависимости от выбранного способа интерполяции.

6. Анкеровка и нахлёст A500 Ø16 в бетоне B30

Rbond = 2,5·1,0·1,15 = 2,875 МПа; l0,an = 435·16 / (4·2,875) = 605,2 мм = 37,8d lan = 1,0·605,2 = 605 мм ≥ 15d = 240 мм → 610 мм Нахлёст, не более 50 % стержней в сечении: ll = 1,2·605,2 = 726 мм = 45,4d → 730 мм Нахлёст, более 50 %: ll = 2,0·605,2 = 1210 мм = 75,7d → 1220 мм

Опубликованные значения для A500С и B30: нахлёст не менее 46d при стыковке не более 50 % стержней и 76d при стыковке всех (Wiki ЖБК). Сайт: 730 мм (45,6d) и 1220 мм (76,3d), длины округлены вверх до 10 мм.
